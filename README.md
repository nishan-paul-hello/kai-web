# Nexus AI - Advanced AI Solutions PWA

A cutting-edge Progressive Web App built with Next.js 16, featuring premium dark mode design, optimized performance, and enterprise-grade AI capabilities.

## 🚀 Features

- ⚡ **Next.js 16** with App Router and React 19.2
- 🎨 **Premium Dark Mode** with #00F07C brand color
- 📱 **Progressive Web App** - Installable on all devices
- 🎯 **Fully Responsive** - Mobile, tablet, desktop, and ultra-wide
- 🔒 **Security First** - Pre-configured security headers
- ⚡ **Lightning Fast** - Turbopack for instant dev server
- 🎭 **shadcn/ui** - Beautiful, accessible components
- 🔤 **Modern Typography** - Inter + JetBrains Mono fonts
- 🪝 **Pre-commit Hooks** - Husky + lint-staged
- 🎪 **Lucide Icons** - 1000+ consistent icons
- 🌊 **Smooth Animations** - Tailwind CSS animations

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **React:** 19.2 with React Compiler
- **Styling:** Tailwind CSS v4
- **Components:** shadcn/ui
- **Icons:** Lucide React
- **Fonts:** Inter (sans), JetBrains Mono (mono)
- **Analytics:** Vercel Analytics
- **Quality:** Husky, lint-staged, ESLint

## 📦 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Initialize Husky:**
   ```bash
   npm run prepare
   ```

3. **Run development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   npm start
   ```
